# 데이터 사전: Auto MPG Dataset

**행 수:** 398행 (데이터), 1행 헤더  
**출처:** UCI ML Repository — StatLib, 1983 American Statistical Association Exposition  
**특이사항:** horsepower에 6개의 결측값('?')이 빈 셀로 표현됩니다.

---

## 변수 목록

### mpg
- **타입:** 연속(continuous)
- **역할 후보:** 종속변수(결과변수) — 연비 예측 목표
- **측정 단위/범위:** 마일/갤런(miles per gallon), 9.0 ~ 46.6
- **결측 여부:** 없음

### cylinders
- **타입:** 순서(ordinal) — 실린더 수
- **역할 후보:** 독립변수(예측변수)
- **측정 단위/범위:** 정수, 3 / 4 / 5 / 6 / 8
- **결측 여부:** 없음

### displacement
- **타입:** 연속(continuous)
- **역할 후보:** 독립변수 — 엔진 배기량
- **측정 단위/범위:** 입방인치(cubic inches), 68 ~ 455
- **결측 여부:** 없음

### horsepower
- **타입:** 연속(continuous)
- **역할 후보:** 독립변수 — 엔진 출력
- **측정 단위/범위:** 마력(hp), 46 ~ 230
- **결측 여부:** **있음 — 6행 결측** (원본 '?', data.csv에서 빈 셀로 표현)

### weight
- **타입:** 연속(continuous)
- **역할 후보:** 독립변수 — 차량 중량 (mpg와 강한 음의 상관)
- **측정 단위/범위:** 파운드(lbs), 1,613 ~ 5,140
- **결측 여부:** 없음

### acceleration
- **타입:** 연속(continuous)
- **역할 후보:** 독립변수 — 0→60 mph 도달 시간
- **측정 단위/범위:** 초(seconds), 8.0 ~ 24.8
- **결측 여부:** 없음

### model_year
- **타입:** 순서(ordinal) — 2자리 연도
- **역할 후보:** 독립변수(통제변수) — 연도별 연비 규제 반영
- **측정 단위/범위:** 정수, 70 ~ 82 (1970 ~ 1982년)
- **결측 여부:** 없음

### origin
- **타입:** 범주(categorical) — 명목
- **역할 후보:** 독립변수(층화 변수)
- **값:** 1=미국, 2=유럽, 3=일본
- **결측 여부:** 없음

### car_name
- **타입:** 식별자(identifier) — 텍스트
- **역할 후보:** 행 레이블 (분석에서 제외 권장)
- **측정 단위/범위:** 제조사+모델명 문자열, 쌍따옴표로 인용
- **결측 여부:** 없음

---

## 결측 데이터 안내
horsepower 컬럼의 6개 결측값은 원본에서 '?'로 표기되어 있으며, 이 data.csv에서는
빈 셀(연속 쉼표 사이 공백)로 변환되었습니다. oh_my_research의 `omr-analyze`는
결측값이 포함된 종속변수 또는 독립변수를 만났을 때 blocked-pending 상태로 전환되어
결측 처리 전략(삭제 또는 대체)을 사용자에게 요청합니다. 이 데이터셋은 해당 동작을
시연하는 데 사용됩니다.
