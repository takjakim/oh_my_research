# PICO / PICOT 및 FRAP — 반증 가능한 연구 질문 만들기

모호한 아이디어를 정밀하고 검정 가능한 연구 질문으로 변환하기 위해 다음
프레임워크 중 하나를 사용한다. 연구 유형에 맞는 것을 고른다; 두
프레임워크 모두 동일한 하위 산출물(질문 + H0/H1 + 변수 표)을 만든다.

## PICO / PICOT (비교 / 중재 연구)

| Letter | 의미 | 매핑 대상 |
|---|---|---|
| **P** | Population / Participants (모집단/참여자) | 누구/무엇을 연구하는가 |
| **I** | Intervention / Exposure / Predictor (중재/노출/예측) | 독립 변수(IV) |
| **C** | Comparison / Control (비교/대조) | 기준 집단/조건 |
| **O** | Outcome (결과) | 종속 변수(DV) |
| **T** | Time (선택, 시간) | 추적/측정 구간 |

**템플릿 질문:** *[P]에서, [I]는 [C]와 비교했을 때 [O]를 변화시키는가
([T] 동안)?*

예시: *건강한 성인(P)에서, 매일 200 mg 카페인(I)은 위약(C)과 비교했을
때 단순 반응시간(O)을 줄이는가?*

## FRAP (기술 / 연관 연구)

| Letter | 의미 |
|---|---|
| **F** | Focus — 관심 현상 |
| **R** | Relationship — 검토하는 연관성 |
| **A** | Antecedent / 예측 변수 |
| **P** | 연관성이 성립하는 모집단 |

**템플릿 질문:** *[P]에서 [A]와 [F] 사이의 관계는 무엇인가?*

## 질문에서 가설로

- **H0 (귀무가설):** 효과 없음 / 차이 없음 / 연관 없음
  (예: "평균 반응시간은 카페인과 위약 사이에 차이가 없다").
- **H1 (대립가설):** 진술된 효과가 존재함; 연구자가 예상 방향을
  진술했을 때만 **방향성**을 부여한다
  (예: "평균 반응시간은 위약보다 카페인에서 더 낮다").

## 변수 표 작성 지침

모든 변수에 대해 기록한다:

- **Role(역할):** IV(예측), DV(결과), 또는 covariate(공변량).
- **Type(유형):** continuous, binary, categorical(>2 levels), count,
  time-to-event.
- **Measurement scale(측정 척도):** nominal, ordinal, interval, ratio.

Type + scale + design(대응표본 vs 독립, 집단 수)이 바로 3단계의
`references/test-selection.md` 결정 표가 소비하는 입력이다 — 여기에
정밀하게 기록한다.
